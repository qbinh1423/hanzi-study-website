# Hanzi Study
An interactive, accessible Chinese vocabulary learning web application built with Next.js, Tailwind CSS, and Framer Motion. The application focuses on spaced repetition, stroke handwriting practice, and responsive, accessible design.

# Key Features
## Smart Flashcard Deck

Interactive 3D flip card animations showing Hanzi characters, Pinyin, English translations, and example sentences.
Spaced Repetition System (SRS) rating actions (Again, Hard, Good, Easy).
End-of-session performance breakdown and summary.
Web Speech API integration for Chinese pronunciation playback.
Integrated shortcuts for handwriting stroke order practice.

## HSK Curriculum Navigation
Categorized levels from HSK 1 to HSK 6 with locked/unlocked progress tracking.
Real-time progress bar reflects session completion.

## Tech Stack
Framework: Next.js, React.js
Styling: Tailwind CSS
Animations: Framer Motion
Language: TypeScript / JavaScript
